# Restaurant-Sales-Analytics using Python
#Project Overview
This project analyzes restaurant sales data using Python to identify sales trends, customer purchasing patterns, and business insights. The analysis includes data cleaning, exploratory data analysis (EDA), and data visualization.
📂 Dataset
Restaurant sales dataset
Features include order details, sales amount, customer information, and product details.
🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook
📊 Project Features
Data Cleaning and Preprocessing
Exploratory Data Analysis (EDA)
Sales Trend Analysis
Revenue Analysis
Product Performance Analysis
Data Visualization using Matplotlib
📈 Sample Visualizations
Sales Trend Chart
Revenue Analysis
Product-wise Sales Distribution
Monthly Sales Analysis
🚀 How to Run
Clone this repository.
Open the Jupyter Notebook.

Install the required libraries:

pip install pandas numpy matplotlib
Run all notebook cells.
